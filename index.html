Stage empty

Drag a character or a model file onto the stage, or double-click a character to place it.

Export

Character

Select a character on the stage.

G move, R rotate, S scale, F fit body, Shift+F fit face, Delete removes.

Meshes

Uncheck a mesh to hide it. Hidden meshes are left out of the export.

Animation

Check a folder to include every clip inside it. Checked clips are written into the GLB. If none are checked, the playing clip is included. Textures are resized to 1024.
